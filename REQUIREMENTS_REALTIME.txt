# Required Packages for Real-time Financial Data Integration

## Core Dependencies

```txt
# HTTP requests library (for API calls)
requests>=2.28.0

# Django caching with Redis
django-redis>=5.2.0

# Redis Python client
redis>=4.3.0

# (Optional) For task scheduling
celery>=5.2.0
celery-beat>=2.4.0
```

## Installation

### Quick Install (All at once)
```bash
pip install requests>=2.28.0 django-redis>=5.2.0 redis>=4.3.0
```

### By Component

**Minimal Setup (Development)**
```bash
pip install requests
# Uses Django's built-in in-memory cache
```

**With Redis (Production)**
```bash
pip install requests django-redis redis
```

**With Automated Tasks**
```bash
pip install requests django-redis redis celery celery-beat
```

## Package Details

| Package | Version | Purpose | Required |
|---------|---------|---------|----------|
| `requests` | >=2.28.0 | HTTP calls to FMP API | ✅ Yes |
| `django-redis` | >=5.2.0 | Redis cache backend | ⭕ Optional* |
| `redis` | >=4.3.0 | Redis client library | ⭕ Optional* |
| `celery` | >=5.2.0 | Task queue | ❌ No |
| `celery-beat` | >=2.4.0 | Scheduled tasks | ❌ No |

*Required for production, optional for development (can use in-memory cache)

## Installation Commands by Environment

### Development Environment
```bash
# Minimal setup with in-memory cache
pip install requests

# Or with local Redis
pip install requests django-redis redis
```

### Production Environment
```bash
# Full setup with caching and task scheduling
pip install requests django-redis redis celery celery-beat
```

### Docker Environment
```dockerfile
FROM python:3.9

WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt

# Also install Redis if using containerized Redis
RUN apt-get update && apt-get install -y redis-server

CMD ["gunicorn", "config.wsgi:application", "--bind", "0.0.0.0:8000"]
```

## Troubleshooting Installation

### Issue: `pip install redis` fails
```bash
# Try upgrading pip first
pip install --upgrade pip
pip install redis

# Or specific version
pip install redis==4.3.0
```

### Issue: Redis connection refused
```bash
# Verify Redis is running
redis-cli ping  # Should return "PONG"

# Or start Redis:
redis-server  # Linux/macOS
net start Redis  # Windows (if installed as service)
```

### Issue: `No module named 'django_redis'`
```bash
# Install with exact package name
pip install django-redis

# Not
pip install django_redis  # Wrong!
```

### Issue: Certificate/SSL errors
```bash
# For certain networks, may need to bypass SSL verification
pip install --trusted-host pypi.python.org --trusted-host files.pythonhosted.org requests
```

## Verification Checklist

After installation, run this to verify everything:

```bash
python manage.py shell << 'EOF'
print("Checking dependencies...")

# 1. Check requests
try:
    import requests
    print("✓ requests")
    r = requests.get("https://www.google.com", timeout=5)
    print("  ✓ Can make HTTP requests")
except Exception as e:
    print(f"✗ requests: {e}")

# 2. Check django-redis
try:
    import django_redis
    print("✓ django-redis")
    from django.core.cache import cache
    cache.set("test", "value", 10)
    if cache.get("test") == "value":
        print("  ✓ Caching works")
except Exception as e:
    print(f"✗ django-redis: {e}")

# 3. Check redis (if using)
try:
    import redis
    r = redis.Redis()
    r.ping()
    print("✓ redis (connected)")
except:
    print("⭕ redis (not installed or not running)")

# 4. Check real-time service
try:
    from api.realtime_service import RealtimeDataService
    print("✓ Real-time service module")
except Exception as e:
    print(f"✗ Real-time service: {e}")

print("\n✅ Dependencies verification complete!")
EOF
```
